Open Scanline

Local-first scanning, image processing, and OCR in Rust. Acquire from flatbed and document scanners, clean up the pages, and export images, searchable PDFs, and multipage TIFF or PDF — all on your own machine.

One command-line tool, an optional desktop GUI, and a public Rust library. No cloud service, no accounts, no telemetry.

What you can do

  • Acquire single pages through mock, file, WIA, SANE, and eSCL sources, plus one-session ADF batches when the device advertises the requested feeder controls.
  • Maintain scanners with capability-aware, device-advertised controls where available, and clearly simulated controls for the mock source.
  • Process crops, rotation, flips, color and level adjustments, deskew, white balance, sharpening, document cleanup, and film-oriented controls.
  • Export PNG, JPEG, TIFF, WebP, BMP, GIF, PDF, multipage TIFF, and multipage PDF, including searchable and password-protected PDFs.
  • Read text with built-in offline template OCR, optional local OCRS model packs, or optional Tesseract integration.
  • Run models locally with user-supplied ONNX image models through an explicitly selected, version-matched worker.

Quick start

# Build a core-only binary (no GUI, OCRS, or ONNX)
cargo run --no-default-features -- scan --device mock --out scan.png \
  --width 320 --height 240

cargo run --no-default-features -- process --in scan.png \
  --out processed.png --invert

# Or launch the desktop interface with the default feature profile
cargo run -- gui

The repository pins Rust 1.91.0. Scanner hardware is optional: the built-in mock and file sources need none.
